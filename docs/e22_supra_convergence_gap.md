# Full Supra convergence investigation

The 6,400-update ParticleGAN adapter remains behind the original published
ordinary-LoRA recipe: validation velocity RMSE is 0.086016 versus 0.073333.
The gap also appears under the same frozen final critic, so it is not solely
a disagreement between the reporting metric and the learned game. The
original examples used AdamW reconstruction training; their architecture,
optimizer and objective differ from the new complete routed formulation.
This comparison does not isolate a ParticleGAN optimizer regression.

All completed training and evaluation artifacts remain unchanged. These
diagnostics use the archived ParticleGAN `f459cb6d` source that produced the
run. The subsequent `89a56efd` commit changes routing validation and diagnostic
synchronization, rather than the game formulation. Output errors and residual
alignment are diagnostic observations only: no reconstruction objective,
output guard, stopping rule, or checkpoint selection is introduced.

## What the real checkpoint rules out

`scripts/diagnose_e22_supra_noise_gap.py` loads the saved frozen teacher,
complete adapter and critic without loading T5 or the VAE. Native CUDA BF16
predictions on the first four validation contexts match the completed
comparison's per-record errors exactly. The edit and preservation contexts
are the next batches selected by the saved data stream, at updates 6,401 and
6,405; preservation noise draws are matched diagnostic draws rather than a
claim to replay all intervening training updates.

The saved critic supplies restorative output-space game gradients on every
sampled clean and noisy residual. Mean raw-residual cosine is +0.786 on edits,
+0.797 on preservation, and +0.768 on validation. Centered gradient fractions
are 0.986, 0.942 and 0.883. The local score curvature is restorative in all
16 tested patch-coordinate directions. This falsifies a reversed game
gradient or a pooled linear critic that misses the measured spatial errors.
It does not establish that the actual parameter-space Adam step is optimal.

The shared bank has dense gradients, checkpoint replay is exact, and no
structural move was accepted during the complete run. An accepted split's
selection error therefore cannot explain this run's gap. Mechanical API,
replay and stability tests do not compare convergence speed on this host.

Evidence: `outputs/e22-convergence-gap/critic-geometry.json`, generated by
`scripts/diagnose_e22_supra_critic_geometry.py` with the actual native residual
payload. The critic geometry calculation runs in CPU FP32; its host residuals
come from exact native CUDA BF16 forwards.

## Noise changes the problem, without reversing its direction

Eight fixed private-stream evaluations leave all policy clocks and training
RNG streams untouched. They are perturbation samples, not training replicas
or a seed sweep.

| Observation | Edit batch | Preservation batch |
| --- | ---: | ---: |
| Clean residual RMSE | 0.05110 | 0.03884 |
| Original 6,400-update adapter RMSE | 0.03787 | 0.02316 |
| Single noisy draw versus clean output, RMS | 0.01801 | 0.01269 |
| Noisy mean versus clean output, RMS | 0.01203 | 0.00870 |
| Centered output noise RMS | 0.01341 | 0.00924 |
| Noisy-mean residual RMSE | 0.04998 | 0.03767 |
| CFG variance / mean branch variance | 12.36 | 12.46 |
| Mean noisy / clean parameter-game-gradient cosine | 0.958 | 0.984 |

Conditional and unconditional DV12 draws are largely uncorrelated. Under
CFG 3, the guided perturbation is `3*delta_cond - 2*delta_uncond`, and its
variance is `9*Vcond + 4*Vuncond - 12*Cov`. The actual complete host exhibits
the predicted amplification. Training noise is substantial relative to its
remaining errors, and changes the average parameter gradient as well as
its variance. However, the mean output slightly improves these paired
residuals and individual parameter gradients retain positive alignment with
the clean game gradient. Noise is a plausible efficiency cost, not an
established explanation of the complete quality gap.

At `blocks.8.cross_attn.q`, 73% of edit codes and 59% of preservation codes
exactly equal a support atom. DV12 excludes zero support distance to give
native particle points a nonzero perturbation radius; for routed mixtures,
this creates a discontinuity between exact selection and approaching that
selection. A matched complete-model replay suppresses exact-atom noise while
still consuming every native random draw. It changes individual outputs by
0.01244/0.00682 RMS, but barely changes aggregate noise or mean game payoff.
Suppressing the entire hot site likewise leaves aggregate noise nearly
unchanged. This corner is real, but the replay does not establish it as the
dominant cause.

Evidence: `native-noise/noise-gap.json`, `generator-noise.json`, and
`native-atom-replay/atom-replay.json` under
`outputs/e22-convergence-gap/`. Native atom replay matches every previous
noise-panel residual exactly, consumes identical random draws in each arm,
and leaves the controller state unchanged.

## Preservation units and the critic anchor

The integration multiplies both preservation adversarial payoffs by 0.1
while retaining the full native KA2 penalty. It also sends weighted payoffs
to the controller, which measures their difference in fixed `log(2)` units.
This makes the preservation penalty ten times stronger relative to its
adversarial payoff, and understates controller payoff imbalance by ten.
The actual unweighted preservation G gradient is already weaker than the
edit gradient; after task weighting its per-unit-residual correction is
roughly twenty times weaker. This is an integration formulation issue to
qualify, rather than an output-metric criterion to add to ParticleGAN.

The critic's stationarity proposal reaches 9.4e-38, but its actual learning
rate remains about 0.00294 because the table-linked floor dominates. This
does not freeze the KA2 average through a learning-rate dependency: KA2 alpha
reads Adam surprise evidence and game trust, not the proposed learning rate.
The critic average nevertheless is unchanged from update 3,200 onward, with
alpha zero and anchor weight one by update 4,000. These are native control
decisions, not corrupted checkpoint state.

A native Adam/KA2 critic-step counterfactual removes only anchor weight,
retaining caps, learning rate, optimizer state and shared noise. It gives
5.46 times the edit-batch adversarial decrease and 2.04 times the
preservation decrease. The downstream G gradient changes by 6.79%/1.72%,
with almost unchanged direction. The anchor causally restricts this local
critic update, but stronger critic adaptation alone is not evidence of a
better coupled game or safer long-term training.

Evidence and exact units: `docs/e22_supra_game_controls.md` and
`outputs/e22-convergence-gap/native-anchor-step.json`.

The generator learning rate remains 5e-5 until update 5,880, then halves for
the last 520 updates. Thus premature early LR settling cannot explain the
gap already present at update 1,600. Its AMSGrad denominator has increasingly
old maxima: at 6,400 the coordinate median of the maximum/current second-
moment denominator ratio is 2.589, and 68.7% of coordinates exceed two.
The down/bridge/up medians are 3.237/3.076/2.178. This is a concrete native
optimizer-memory mechanism that can slow late adaptation without failing
stability tests. These coordinate ratios are not gradient-weighted effective
step ratios and do not alone prove that forgetting maxima repairs the game.
Evidence: `outputs/e22-convergence-gap/generator-memory-audit.json`.

The last saved G first moment is also its applied gradient, because native
beta1 is zero. That update, 6,400, is a preservation update. Reconstructing
that same step with only the denominator
changed gives a branch step norm of 0.00072084 with AMSGrad versus 0.00168994
with the current second moment: 2.344 times larger. Every one of the 71 sites
has attenuation, ranging from 1.482 to 5.217 times. Router and bank norm
ratios are 1.244 and 5.952. This establishes actual local step attenuation,
rather than inferring it from unweighted coordinate statistics. It does not
establish that larger steps improve long-term training. The fifth branch
changes the entire generator optimizer owner, including router/table/noise,
so its outcome cannot be assigned to branch weights alone. Evidence:
`outputs/e22-convergence-gap/generator-step-memory-witness.json`.

## Learned representation conditioning

A separate complete-host capture compares original fresh LoRA features,
fresh particle features using the required public deterministic initializer,
and the trained particle export. All 71 fresh particle sites have zero
preactivation saturation above magnitude three. Their mean tanh derivative
is 0.9575/0.9605 on edit/preservation batches. Initialization is not the
observed saturation problem.

After training, `blocks.7.cross_attn.q` has bridge code-path RMS 2.863 versus
hidden-path RMS 0.863. Its saturation fraction is 59.5%, mean derivative
0.0887, and centered feature covariance effective rank falls from 5.60 to
1.10. `blocks.8.cross_attn.q` similarly has code-path RMS 2.808 versus hidden
0.691, and effective rank falls from 5.46 to 1.23. These are bank-driven
conditioning bottlenecks in the integration's `up(tanh(bridge(hidden,code)))`
architecture. A low effective rank can also reflect useful specialization;
it is not alone proof that this representation cannot express the teacher.

Clean routing inspection confirms nearly constant extreme-atom selection.
At block 8 cross-q every token chooses row 100, whose norm is 20.506 versus
a bank median of 3.558. Its mean weight is 0.99999845, entropy 2.38e-5, and
median code/query Jacobian norm 7.03e-8. That Jacobian is the routed
softmax-weighted bank covariance divided by sqrt(4), so nearly one-hot
routing makes query learning ineffective. Row 100 is also the best aligned
direction at this site; this is not merely an incorrectly chosen direction.
At block 1 cross-q, however, selected-row cosine is 0.641 versus the best
unit-key cosine of 0.967, and removing key-norm variation changes argmax for
99.9% of tokens. The shared key/value dot-product rule can reward extreme
value norms as well as useful alignment. Across sites, a diagnostic
unit-key argmax calculation changes 72–73% of selections. Native routing
remains unchanged in all measurements.

Evidence: `branch-geometry/branch-geometry.json` and
`key-geometry/key-geometry.json` under `outputs/e22-convergence-gap/`.
Fresh zero-output/base parity and trained/native-residual parity are exact.
The next architecture qualification should keep the original unbounded
linear LoRA path while applying bounded bank modulation, and isolate key
conditioning from value magnitude. These are integration candidates to test
under the native game; neither is a proven replacement based on this capture.

## A separate reproducible native controller defect

Native learned-output-noise floor eligibility includes the noise parameter's
own stationarity tester. A state-level CPU witness settles all other non-D
groups to 1/64, sets the raw sigma below the initial floor, and leaves the
noise tester at one. The physical sigma stays at 0.125, its log-parameter
gradient is zero, and 24 native observations declare that tester frozen
without lowering its scale. The clamped parameter therefore vetoes its own
floor release. A reporting-only exclusion of the noise tester gives the
intended mobility floor of 0.011297 in this witness.

ParticleGAN feedback: define release eligibility so a clamped learned-noise
parameter cannot veto its own release; add a regression where the other
groups settle after log sigma falls below the initial floor. Apply the rule
consistently in public policy and native trainer. This reproduces a core
control defect, but current router/table scales of one independently bind
the floor, so it does not establish the cause of the present 6,400-step gap.
Evidence: `scripts/diagnose_e22_noise_floor.py` and
`outputs/e22-convergence-gap/noise-floor-witness.json`.

## Fixed-budget causal qualification

The next diagnostic is declared before running: five complete native-game
branches, all strictly restored from the same update-6,400 checkpoint, each
receiving 256 more updates and the same sampled-context stream.

1. Unchanged native control.
2. Compute DV12 draws but suppress their application, retaining RNG progress.
3. Use unweighted D training and unweighted controller payoffs on both pools;
   retain the existing 0.1 preservation weight on the G backward objective.
4. Remove only the native critic anchor weight, retaining A/B caps and Adam.
5. Disable only generator-optimizer AMSGrad use of the historical maximum,
   retaining its existing current first/second moments, rates and controllers.

The final horizon is fixed for every branch. The original learned-feature
structural criterion remains in effect. Game progress is reported under both
the common frozen initial critic and each branch's final critic. Clean output
errors are reported afterward and never select, stop or configure a branch.
This is a short causal diagnostic of late training, not a replacement for a
matched full-budget comparison or an established production change.

All five branches completed at update 6,656. Every starting full checkpoint
matches exactly; all 256 data, paired-Gaussian and DV12 call-shape/RNG checks
match across branches. Frozen hosts remain unchanged, evaluation leaves
training state unchanged, all serving sources are fast, and no structural
move is accepted. The fixed physical output sigma remains 0.125.

| Fixed 256-update branch | Held-out common-D G payoff | Preservation common-D G payoff | Held-out RMSE, evaluation only | Preservation RMSE, evaluation only |
| --- | ---: | ---: | ---: | ---: |
| Native control | 0.993560 | 0.738349 | 0.085789 | 0.051461 |
| DV12 application disabled | 0.993502 | 0.738060 | 0.085785 | 0.051337 |
| Preservation units corrected | 0.993726 | 0.736636 | 0.085804 | 0.050709 |
| Critic anchor disabled | 0.993334 | 0.738169 | 0.085759 | 0.051388 |
| Generator-owner AMSGrad disabled | 0.995494 | 0.737351 | 0.085959 | 0.051027 |

Lower G payoff means better performance against the same frozen starting
critic. The native-game held-out payoffs differ little for noise, hold-unit
and anchor interventions. Removing AMSGrad makes held-out and fit game
payoffs worse. Thus its measured local attenuation is not sufficient reason
to remove the safety mechanism. Corrected hold units improve preservation
game payoff and its reported error, but do not improve the edit game here.
No branch closes the original-example gap. This falsifies these controls as
large standalone repairs at this late checkpoint and fixed budget; it does
not falsify an effect on the earlier training trajectory.

Results, all traces, final exports and diagnostic deltas are under
`outputs/e22-convergence-gap/training-controls-256-final/`. The exact executed
runner is archived there as `source.py`. A partial earlier launch under
`training-controls-256/` is marked aborted and excluded: reporting edits
landed during launch, so it was stopped and restarted with a fixed source
snapshot. No completed original run was changed.

The remaining targeted experiment is a one-update representation
counterfactual. Add an unbounded linear path using the existing up/down
parameters, and subtract frozen reference up/down weights fixed to the same
starting fast G. At the starting point this extra path is identically zero
for clean and perturbed forwards, while its new gradient follows a valid
native-game model. This tests conditioning without a different initial
output, extra trainable parameters, an output loss, or a surrogate gradient.
It is a local witness, not a deployable export or a full-budget repair.

## Identical-point architecture witness

`scripts/diagnose_e22_supra_linear_path_step.py` completed native update
6,401 in both arms. The original complete checkpoint restores exactly,
all clean pre-update outputs and both actual noisy D/G host outputs are
bit-identical, the native critic/Adam step and all training streams match,
and the additional trainable parameter count is zero. Frozen references
retain input derivatives; this is a true model gradient, without a
straight-through substitute. Only fast training G is evaluated; equality
of the pre-existing EMA model's function is not claimed.

| One native update, same starting point | Native path | Additional compensated linear path |
| --- | ---: | ---: |
| Edit-batch common-D G payoff decrease | 0.003634 | 0.005369 |
| All held-out common-D G payoff decrease | 0.0003795 | 0.0009421 |
| Preservation common-D G payoff decrease | 0.0000252 | -0.0001589 |
| Down-parameter game-gradient norm | 0.02300 | 0.08409 |
| Down-parameter actual step norm | 0.004451 | 0.018776 |
| Up-parameter actual step norm | 0.010306 | 0.013106 |

The unbounded input path increases the down-path gradient by 3.66 times and
held-out native-game improvement by 2.48 times in this local step. The
critic and initial output did not change, so this is direct evidence that
the integration's parameterization can restrict a useful game update.
The intervention changes both the local Jacobian and the reachable function
family; it does not isolate tanh saturation alone as the historical cause.
Both actual backwards use the same native updated critic at 6,401, while
the common evaluation judge remains the saved critic at 6,400.
Preservation gets worse, however: the faster edit update is not a qualified
overall repair. Reported held-out RMSE moves from the common initial
0.086016 to 0.085990 native and 0.085880 linear; preservation moves from
0.051466 to 0.051455 native and 0.051532 linear. These values never enter
optimization or candidate selection.

The resulting diagnosis is bounded: the critic direction and API replay
work, while trained bank codes saturate the host's nonlinear input path;
an identical-point intervention improves one native-game edit step.
The five late control interventions do not repair the edit game, and larger
AMSGrad-free steps worsen it. This supports conditioning work in the Supra
adapter and consistent preservation game units. It does not prove how much
of the original 6,400-update gap comes from this path or demonstrate a
long-term advantage over ordinary LoRA.

The next full qualification should compare an unbounded linear input path
with bounded bank modulation against the current host under the same
native game, required public initializer, fixed data/RNG stream and declared
update budget. Preserve task weighting consistently, report both edit and
preservation games, and select only the final fixed horizon. Assess key
conditioning separately from value magnitude; the current capture supports
testing it, not adopting a normalization rule without evidence. ParticleGAN
core feedback is the reproduced learned-noise floor self-veto and a need
for this composed-host convergence fixture in addition to correctness and
stability tests. Removing native AMSGrad or the critic anchor is not
supported as a standalone repair by these results.

and the executed source snapshot are under
`outputs/e22-convergence-gap/linear-path-one-step/`. The five-arm independent
qualification is
`outputs/e22-convergence-gap/training-controls-256-final/qualification-review.json`.
